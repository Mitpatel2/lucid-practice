# Bundled replay candles

NQ and ES one-minute OHLCV from the local Databento GLBX.MDP3 exchange-week archive covering October 12–16, 2026 trading sessions. Source contracts: NQZ6 and ESZ6. UTC candle-open timestamps. Each file has 6,900 candles. Weekend/session gaps are preserved.

Only timestamp and numeric OHLCV columns are included. No provider request identifiers, download URLs, local paths, usernames, account records, API keys, or original manifests are included. These are market observations, not personal trades. MNQ/MES replay uses NQ/ES prices as proxies.
