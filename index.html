Data coverage & quality

Replay controls & assumptions

Keyboard: Space play/pause · Right arrow step · Escape cancel drawing mode. With the chart focused: ←/→ pan, +/− zoom, End current bar. Numeric stop and target fields are alternatives to dragging.

The last price always comes from the latest revealed source candle. Higher timeframes show a forming candle assembled only from revealed source bars; indicators and model features use completed candles only. Aggregation is UTC-aligned. A step advances exactly one source candle, including missing-data periods. Stops win ambiguous same-bar stop/target touches; gap losses can exceed planned risk. Manual exits fill at the next open. Missing held-instrument data halts with an unresolved position.

No real orders, queue simulation, or verified prop-firm compliance. MNQ/MES use NQ/ES proxy prices. All changes stay local.
